# Requirements Checklist

Select your system's **risk level** to generate the telemetry your deployment is
expected to implement. The action for each item — **Mandatory**, **Mandatory but
Waivable**, or **Good-to-Have** — is read from the
[requirements matrix](requirements-matrix.md).

<div id="orf-checklist"></div>

!!! note "Not a substitute for assessment"
    This checklist reflects risk tier only. As noted under
    [Risk Tiering](risk-tiering.md), agencies should run a parallel data-handling
    assessment, since data classification can raise handling or retention
    requirements independently of risk level.
